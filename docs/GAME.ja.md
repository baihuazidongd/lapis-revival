# ゲーム紹介 · Lapis Re:LiGHTs（宝石幻想：光芒重现 / ラピスリライツ 〜この世界のアイドルは魔法が使える〜）

## どんなゲームか

『Lapis Re:LiGHTs』は、KADOKAWA が主導し KLab が開発・運営するマルチメディアプロジェクト（ゲーム、アニメ、音楽、小説）の中の
スマートフォンゲーム作品です。プレイヤーは**教師（先生／老师）**となり、アイドル魔女を育成する学院で、「魔法で歌う」少女たちを
ステージに立たせていきます。

世界観には素敵な設定がひとつあります。**魔法は歌声を媒介とする**。戦闘中のスキルは「詠唱」であり、ステージ演出と戦闘は同じ表現
ロジックを共有しているため、カードの「スキル名」は楽曲名のように聞こえ、戦闘アニメーションはライブ映像のワンシーンになります。

サービス終了日：2022-10-31。日本語サーバーの終了後、本作の内容はインストール済みクライアントと CDN キャッシュの中にのみ存在する
ようになりました —— これこそが本復活プロジェクトが存在する理由です。

## なぜ復活する価値があるのか

サービス終了後、4年分のコンテンツ量、数千本のストーリー台詞、数万個のボイス、完全な楽曲ライブラリを持つ作品は、技術的には「誰かのスマートフォンに
あるあのインストールパッケージ」だけになってしまいました。こうした作品の存続は、ローカルでのインターオペラビリティ研究にのみ依靠できます。サーバー依存している
ロジックの一部を、監査可能なローカル実装に置き換えることで、コンテンツをふたたびアクセス可能にするのです。本プロジェクトはいかなるサービスの再開も試みず、ゲームコンテンツの配布も行いません。
